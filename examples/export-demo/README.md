# Phase 4 export example

The walk-… subfolder contains a real export made through the Qt export dialog
during the Phase 4 smoke test. It uses the built-in CPU diagnostic mannequin,
not AI-generated artwork. Each export is independent and contains 18 files:
16 single PNG frames, walk_sheet.png, and animation.json.

See docs/export-format.md for coordinate conventions and JSON version details.
