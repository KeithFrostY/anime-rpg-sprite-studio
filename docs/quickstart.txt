Anime RPG Sprite Studio 0.6 — Windows 免安裝測試版

啟動 AnimeRpgSpriteStudio.exe。請保留同一資料夾中的 _internal，不能只複製 EXE。
不需要另行安裝 Python。不需要 API Key，也能使用離線編輯與 CPU 動畫功能。

1. 新增角色並儲存專案到自己的可寫入資料夾。
2. 有現成動畫：選擇方向與幀槽，匯入 1 張或 4 張 256×256 PNG。
3. 測試分層動畫：開啟「分層模板／生成 Walk」，載入內建測試模板，調整參數，
   生成候選，切換四方向檢查，確認後套用。人偶是測試素材，不是 AI 成品。
4. 使用腳底線與前後幀疊影檢查腳滑、接縫、抖動。輔助線不會寫入 PNG。
5. 按「一致性檢查」檢查 16 幀；警告是輪廓規則，不能保證美術或身份一致。
6. 按「匯出…」，驗證通過後產生 16 張 PNG、1024×1024 Sheet 與動畫 JSON。
   不含 Unity。匯出使用新的資料夾，保留先前匯出。
7. AI 候選預設離線 Mock。fal.ai 需要自己設定 Key、即時報價與逐筆付費確認。
   未知費用不會當作零。US$4.50 是本機停止門檻，不是供應商帳單硬上限。

檔案與資料
專案與圖片請存到個人資料夾，不要放入 _internal。
移動專案請搬移整個專案資料夾，或使用另存新檔複製素材。
API Key 只存 Windows Credential Manager；帳本位於 Windows 帳號本機應用資料夾。
刪除程式資料夾不等於刪除 Key 或帳本；不要刪帳本來解除未決費用。

目前限制
這是未簽章的本機測試版，尚未在乾淨 Windows 10/11 環境全面驗證。
未以真實 Key、真實 Windows 憑證讀寫或付費 API 驗收。
單張 AI 圖不會自動拆層或變成完美四方向；分層旋轉可能有接縫與腳滑。
程式若要求網路付費，請先確認 Provider、模型與本次報價；不會自動重試。
背景操作關閉時可能需等候清理／逾時。請保留專案，勿強制終止未決付費請求。
