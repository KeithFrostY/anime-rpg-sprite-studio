# AI 候選、Key 與預算管理

主視窗按「AI 候選／預算」。預設為離線 Mock，不讀取 Key、不要求網路、
不收費；候選圖不會自動加入動畫。正式 Provider 僅有 fal.ai 的
`fal-ai/flux/schnell`，每次一張 256×256 PNG，安全檢查保持開啟。

## Key 設定

1. 在 fal.ai 自行建立 Key，優先限制可用模型為 FLUX.1 Schnell。
2. 在程式 Key 設定輸入，按新增／更換。輸入永遠遮罩，保存後立即清空。
3. Key 只使用 keyring 的 Windows WinVaultKeyring。安全後端失敗即停止，
   不讀環境變數、不使用普通 JSON、不退回明文或其他自動選取後端。
4. 「測試」只 GET 官方價格端點，不執行模型。測試成功不等於有帳單讀取權限。
5. 「刪除」僅移除本機保存的 Key；撤銷供應商 Key 須自行到 fal.ai 操作。

價格端點接受一般 API 權限；帳單端點需要 `billing:usage:read`、
`auth:keys:read`、`account:users:read`。若需要，可自行建立兼具必要權限的
最小範圍 Key；程式不會代為擴權，也不要求你貼 Key 到聊天中。
沒有帳單權限時，已提交請求會保持費用未決並禁止新生成。
官方參考：[認證](https://fal.ai/docs/api-reference/platform-apis/authentication)、
[價格](https://fal.ai/docs/platform-apis/v1/models/pricing)、
[帳單事件](https://fal.ai/docs/platform-apis/v1/models/billing-events)。

## 單次付費流程

1. 明確切換到 fal.ai，輸入提示詞與 Seed。
2. 按「取得官方報價」。程式即時讀取官方單價，不使用永久硬編碼價格。
3. 只接受 USD 及可識別的 image／megapixel 單位；其他計費方式直接禁止提交。
   256×256 一張圖片採保守的一整個計費單位估算及保留，不用歷史平均價格。
4. 報價有效兩分鐘，顯示模型、張數、費用、來源、有效期、安全可用額。
   提示詞、Seed、Provider 或 Key 改變需重新報價。
5. 按提交後會再次詢問本次費用，預設為「否」。只有明確選「是」才授權一筆。
6. SQLite 先原子保留預算並記錄準備提交，再送一次 HTTP POST；不自動重試。
   成功後在帳本選取原請求，手動查狀態、取得候選或要求取消。
7. 候選可另存 PNG。它不保證透明、四方向一致或已分層；不自動拆圖、去背、
   匯入 Walk，生成與現有動畫合成器完全分離。

官方模型欄位參考：[FLUX.1 Schnell](https://fal.ai/models/fal-ai/flux/schnell/api)。
API 使用經過憑證驗證的 HTTPS；授權僅傳送 api.fal.ai 或 queue.fal.run。
圖片僅從 fal.media 及其子網域下載，完全不附 Key；任何重新導向均拒絕。
有逾時、回應大小限制，不讀環境代理設定，不輸出原始伺服器錯誤或 Key。

## 帳本、預算與恢復

帳本在目前 Windows 帳號的本機應用資料目錄，通常位於
`Anime RPG Sprite Studio/ai/budget.sqlite3`。開啟 AI 工具才初始化，應用啟動
不讀 Key、不連網。專案 JSON 與匯出檔不含 Key、預算或帳單。
帳本不保存提示詞原文，只存請求指紋、Key 的不可逆指紋、報價、UTC 時間、
模型、狀態、估算、保留、實際費用、供應商 ID 及事件紀錄。

- 金額使用 Decimal、資料庫以字串保存；月分採 UTC。
- 每月預算 US$5.00，停止門檻 US$4.50。新保留額不得讓確認費用與未決額
  超過 4.50；等於 4.50 可保留。實際費用若較高仍照實記錄，不截斷成上限。
- 全應用、同一帳本的多程序一次只允許一筆進行中或費用未決請求。
  SQLite BEGIN IMMEDIATE 防止兩個視窗同時通過；真正提交前再檢查一次。
- RESERVED 表示尚未跨過網路提交邊界，可明確釋放。SUBMITTING、UNKNOWN、
  已提交、失敗、完成或取消，都不能推定免費；未知保留額跨月、跨重啟保留。
- 按「核對帳單」查詢官方逐筆事件；只有匹配供應商請求 ID 與模型的完整
  分頁證據才能核對。查不到資料、權限不足或格式錯誤不當作零。
  零費用也需要明確匹配的帳單事件。
- 工作狀態與費用待核對是不同欄位；工作完成不會自動解除費用攔截。
  發現新的跨月調整或無法解讀的匹配帳單時保留舊確認證據並標為待重核，
  阻止新生成及已保留但尚未送出的請求。
- 取消只向原請求發送一次取消要求，不會釋放費用。官方說明取消執行中的
  工作是向模型發信號，並非保證沒有執行或收費。
  [取消文件](https://fal.ai/docs/api-reference/inference-api/queue/cancel)

若提交逾時而沒有取得供應商 ID，程式不會重送或提供強制清零。這類不確定
請求需要供應商人工協助核對，本版不能自動恢復成可再次生成。
帳單查詢最多 20 頁且單次時間範圍受 90 日限制，超出時保持待核對。
網路請求無強制中途斷線；關閉工作中的視窗會等待操作完成或逾時，避免遺失
提交結果。沒有背景自動重送、輪詢、模型切換或費用重置。

本次未確認一般自助帳戶有可設定為 US$5 的真正月度硬限制；不要把本程式

## 驗證範圍

開發與測試一律假 Key、假 HTTP、暫存帳本，測試禁止網路與真實 WinVault
讀寫。畫面快照的金額為測試資料，不是正式模型報價。真實網路、真實 Key
與付費生圖尚未執行驗證；正式收費前仍須在程式中逐筆明確確認。
