# 單方向動畫：實作計劃

範圍：保留原始背景，從網格圖片切割影格，預覽單方向行走或攻擊，匯出 PNG、Sprite Sheet 和 JSON；既有四方向流程維持原有格式。

1. 建立獨立的切割服務：驗證圖片、網格尺寸和邊界，依左至右、上至下切割，保留原始像素及背景。以六個不同顏色格子的測試圖驗證順序與像素，並測試無效網格。
2. 建立單方向動畫資料與匯出服務：保留影格順序、方向、類型、FPS 和循環設定；輸出獨立 PNG、橫向 Sprite Sheet 和 JSON。驗證完整內容與像素，避免覆蓋既有資料。
3. 建立獨立視窗：選擇圖片、設定欄列、查看切割線與縮圖、調整順序、播放與匯出；行走預設循環，攻擊預設播放一次，FPS 預設 8。
4. 在主視窗加入入口，說明此流程保留背景及切割可能裁切武器；更新使用文件。
5. 執行離線單元及介面測試，使用使用者提供的範例檢查切割和預覽；彙報測試及限制。

設計決定：新功能是獨立流程，不強行將六幀寫入目前只支援四幀的專案資料模型。切割時遇到圖片尺寸不能整除網格，應提示使用者，而不是悄悄丟失像素。匯出尺寸依切割後原圖大小，以保留原背景及像素；如需縮放至 256×256，應在後續設計中明確決定。
